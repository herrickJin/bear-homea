# 材质 / 配色参考档案 — 城投南山长投·领峯 D143 (123kanfang 交互设计方案)

> **用途定位**：本文件是**参考档案**。新工具第一版只做「还原原始建筑测量图」，
> 不做方案视图，因此配色信息暂不直接显示；切到方案视图时本档案可直接取用。
> 房间基准表的机读版见 `rooms.json`，材质机读版见 `materials.json`。

## 0. 数据来源与坐标基准

| 项 | 值 |
| --- | --- |
| 房间/面积/多边形 | `archive/floorplan-source/ViewData.json` |
| 3D 几何 + 材质 + 贴图 | `archive/floorplan-source/floordata0.glb` (glTF 2.0 binary, 8651780 bytes) |
| 墙体线稿平面图 | `archive/floorplan-source/plan-123kanfang.png` (1563×1363 px) |
| 生成脚本 | `archive/floorplan-source/derived/extract_rooms_materials.py` |

| 坐标基准 | 换算 |
| --- | --- |
| 单位 | 1 GLB 单位 = **10 mm** |
| 面积 | ViewData `Rooms[].Area` 直接是 **㎡**；几何面积按 1 单位² = 0.0001 ㎡ 换算 |
| 平面坐标 | `GLB_X_mm = ViewData_X × 10`，`GLB_Z_mm = −ViewData_Y × 10` |
| 竖向 | GLB `Y` 向上，地坪 0、顶棚 280 (2800 mm) |
| 平面图像素 | `px = X_glb + 927.508 ; py = Z_glb + 662.038` |

> ⚠️ **轴向提醒**：ViewData 的 `Y` 与 GLB 的 `Z` **方向相反**（ViewData Y 向上为正，GLB Z 向下为正）。
> 只按“同坐标系”直接取用 Z 会把整套房上下颠倒。

**复现方式**

```bash
cd archive/floorplan-source/derived
python3 extract_rooms_materials.py            # 重写 rooms.json / materials.json / materials.md
python3 extract_rooms_materials.py --check    # 只打印统计, 不写文件
```

> 脚本只用标准库即可跑出房间/材质几何（numpy 缺失时自动退回纯 Python，两者算出的材质面积完全一致）；**Pillow 缺失时贴图取色与像素定位会写 null 并注明原因**。

### 1.1 同名房间的区分判据

- **客厅** (`eHaXGv38` / 客餐厅)：客餐厅一体化 (LDK): 北侧起居 (沙发 M_多人沙发_* / 茶几 / 地毯, GLB Z −331.7…−69) + 南侧餐区 (餐桌 M_餐桌_* + 餐椅×4, GLB X 234…316, Z 72…260)。『客厅·LDK 餐厅区』是按 客厅区 polygon 在 Z=52.97 (储物间北墙线) 处切分出来的派生分区, 不是独立房间; 第一版不另立『餐厅』。玄关柜/酒柜/装饰柜贴东墙 (X≈465…500)。
- **主卧** (`mCOSmg5M` / 主卧)：主卧: 西侧 X −791.5…−460.5, 北侧 Z −428.5…53.0; 与主卫 EX4vhDXo 共墙 (Z 52.97…65.97)。
- **北次卧** (`f1qYqHqH` / 次卧)：北次卧 (客卧位): 面积 10.07㎡ 为两个次卧中较大者, 与主卧共墙 (X −462.5…−460.5), 内含衣柜/装饰画/地毯而无书桌 ⇒ 判定为客卧位。123kanfang 侧名称同样叫『次卧』, 属推断。
- **主卫** (`EX4vhDXo` / 卫生间)：主卫: 4.00㎡, 直接紧贴主卧南侧 (共墙 Z 52.97…65.97), 内含 8 组浴室柜 + 马桶 + 地漏 + 暖风浴霸 ⇒ 为主卧套卫。
- **南次卧** (`g3cnKYnd` / 次卧)：南次卧 (次卧位): 面积 9.40㎡, 位于主卧南侧; 内含『衣柜带转角书桌』+ 单椅 ⇒ 带书桌功能, 判定为次卧/书房型。123kanfang 侧名称同样叫『次卧』, 属推断。
- **储物间/多功能角** (`XrCzEEni` / 书房)：原始户型命名『储物间/多功能角』, 尺寸 1.99×3.30 m (19925×32975 mm)。与公卫 qOPrZ97W 共用同一段墙 (X −161.5…−139.5 墙带), 动线上是入户过渡区。原始户型待现场照片确认; 123kanfang 方案将此处改为电竞房 (推拉门 + 电竞椅×2 + 背景墙)。方案内实为电竞房: 西墙贴 M_电竞房背景墙_* 背景墙, 内含 2 组 760×1130×740 mm 桌台 (GLB 节点 173/174)。
- **公卫** (`qOPrZ97W` / 卫生间)：公卫: 2.13㎡, 仅马桶 + 地漏, 紧邻盥洗区/过道, 与主卧、主卫均不相邻 ⇒ 为公共卫生间。
- **厨房** (`WFGji10I` / 厨房)：厨房: 5.33㎡, 位于东南角 (GLB X 83.75…324.5, Z 343.97…565.47), 沿东/南两侧布置厨柜。
- **生活阳台** (`z5u59ReE` / 生活阳台)：生活阳台: 8.54㎡, 位于北端 (GLB Z −526.03…−392.53), 含阳台洗衣机柜 (X 439.7…499.8)。
- **客厅·LDK 餐厅区**（派生）：由 客厅区 polygon 在 Z=52.97 (客厅区南侧凹口 = 储物间北墙) 处切分得到的南半部分。该切分线同时落在『沙发组 (Z ≤ −56)』与『餐桌组 (Z ≥ 72)』之间的空档里, 所以切分结果与家具布置自洽。面积由 shoelace 对切分后多边形复算。
