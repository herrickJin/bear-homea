## 0. 读数约定

| 项目 | 约定 |
| --- | --- |
| 单位 | 全部为 **毫米 (mm)**; GLB 原始 1 单位 = 10 mm |
| 坐标系 | 与 GLB / ViewData.json 完全一致, 原点即模型原点 |
| X / Z | 水平面两轴; **Y 向上**, 地坪 Y=0, 顶棚 ≈ 2800 |
| `center` | 家具平面包围盒中心 `[X, Z]` (mm) |
| `size.w / size.d` | 沿家具自身坐标的 **oriented 尺寸**: w=本地 X(宽/长), d=本地 Z(进深), h=高 |
| `aabb_size` | 世界坐标轴对齐包围盒: w=X 向, d=Z 向, h=Y 向 |
| `rotation_deg` | 家具自身 **本地 +X 轴**(宽度方向)在水平面的方位角, 0°=+X, 转向 +Z 为正 |
| `facing_deg` | 家具自身 **本地 +Z 轴**方位角 (多数柜体为正面/进深轴) |
| `base_y` | 家具底面标高 (mm), 0 = 落地, 其余为离地挂装 |
| 房间矩形 | 由 ViewData.json 房间多边形换算: `GLB_X = ViewData_X×10`, `GLB_Z = −ViewData_Y×10` |

## 4. 布置逻辑解读

- **厨房是 U 型(三面橱柜), 既不是一字型也不是单纯 L 型**: 地柜共 **3 段 / 3 面墙** (墙位 X=1115.7、墙位 X=3035、墙位 Z=5387.4), 柜体为 厨柜_50cm×11、烤箱柜_80cm×2、抽油烟机柜_80cm×1。水槽落在 墙位 X=1115.7, 燃气灶 + 抽油烟机 + 烤箱柜落在 墙位 Z=5387.4 —— 「洗」在一头、「炒烤」在另一头、中间留出切配台面, 三面连续无过道断口, 是典型 U 型厨房而非一字型。
- **主卧是「整墙定制衣柜 + 书桌」**: 房间只布置一件大件 `带书桌衣柜` (宽 4675.2 × 深 614.8 × 高 2500.1 mm), 紧贴西墙、北墙, 长度占该墙 **97%** —— 是真正的整墙柜; 衣柜与书桌合并成一个模块 (资产名本身就是「带书桌衣柜」), 再配 `床_180cm` + `床头柜_50cm_左` ×2, 属于「整墙柜 + 睡眠区」强收纳卧室。
- **两间次卧是两种截然不同的方案**: `次卧(f1qYqHqH)` 只用一件**独立** `衣柜` (宽 1859.2 × 深 600.6 mm, 只贴东墙、北墙, 占 1 面墙), 其余留给床与飘窗; `次卧(g3cnKYnd)` 则用 `衣柜带转角书桌` (宽 1874.8 × 深 1735.7 mm, 同时贴西墙、南墙, 跨 2 面墙), 把衣柜与书桌做成 L 形连体塞进转角 —— 同样一套柜体, 一个当纯收纳, 一个同时出收纳 + 办公, 后者更省面积。
- **书房 (书房, 净 1.99 × 3.30 m) 实际按「电竞书房」布置**: 家具只有 电竞房背景墙×1、电竞椅×2、吸顶灯×1、推拉门_200cm×1、单块_单玻璃_260cm×1、平开窗开扇左×1、平开窗玻璃中上×1、空调入风口_120cm×1、空调入风口_240cm×1。`电竞椅` ×2 + `电竞房背景墙` 出现, 而没有独立书架/书桌 —— 说明这版方案把 1.99×3.30m 的小房间让位给了电竞功能。
- **生活阳台只做家政, 不做休闲**: 唯一一件家具是 `阳台洗衣机柜_125cm` (宽 1335 × 深 600.7 × 高 2601.5 mm, 中心 X=4697.4 Z=-4592.8, 方位 90°), 洗衣机位与上方储物一体; 其余 11 件全是门窗构件, 有限面积全部让给洗衣/晾晒。
- **客餐厅是「一厅两用 + 整面展示柜」**: 靠入户门一侧是 `装饰柜×1、组合柜背景墙×1、玄关柜×1、酒柜×1、嵌入式冰箱柜_90cm×1` 这条柜体带, 把玄关、冰箱、展示、酒柜全部收进同一面墙; 餐区 `餐桌` + `单椅` ×4, 客厅区 `多人沙发` + `茶几` + `地毯` + `凳子` + `落地灯`; 所有柜体贴墙, 房间中轴留空给通行。
- **两间卫生间分工不同**: 卫生间(EX4vhDXo) (4.00 m²): 浴室柜×1、暖风浴霸×1、马桶×1、花洒×1; 卫生间(qOPrZ97W) (2.13 m²): 马桶×1、花洒×1 —— 带 `浴室柜`+`暖风浴霸` 的是主卫, 只有马桶/花洒的是客卫, 两卫不重复投资。
