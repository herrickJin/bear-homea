# 熊熊之家 · 视觉方向与设计 Token

> 单一真源。Token 定义在 `src/styles/tokens.css`，本文件解释「为什么」并规定「怎么用」。
> 改任何颜色 / 字号 / 间距：先改 tokens.css，再全局消费，页面里不出现裸十六进制。
> **当前生效方向：3.2「样板画廊 · 瀑布流」**（见第八~十一章）；第二~七章为现行规范。

## 一、风格定位

**「样板画廊 · 暖色签名」——家还没装完，App 是未来之家的画廊。**
（3.0 定于 2026-10-11；3.1 同日增补：品牌暖色元素回归）

用户是第一次装修的小两口，装修要熬 6~10 个月，每天在小红书收集的是**图片**。
App 的第一职责是把它们大幅、安静、体面地挂出来；同时保留这个家的品牌记忆——
**小熊、胶带、蜂蜜黄、陶橘**是「签名」，出现在固定的几个位置，不与图片争抢。

- **基调**：暖白墙面做底，图片是绝对主角，界面退后。安静、克制、留白。
- **深度**：hairline + 井底两级，常规界面零阴影。
- **签名（暖色层，只驻壳层）**：胶带 eyebrow（一屏一次）、小熊（品牌位 + 空态）、
  蜂蜜黄（只在胶带上）、陶橘（焦点环/标题句点）。内容卡片区一律中性。
- **出处**：画廊白墙 / 美术馆图签 / 手帐胶带。不做满铺拟物，隐喻只出现在签名位。

## 二、色彩

| Token | 色值 | 角色 |
|---|---|---|
| `--c-ink` | `#1f2421` | 标题与正文（带一丝绿意的近黑） |
| `--c-ink-2` | `#434a45` | 次级标题 |
| `--c-mute` | `#6d736e` | 辅助文字（白底 ≈4.9:1） |
| `--c-faint` | `#a3a8a2` | 弱标注、页脚 |
| `--c-line` | `rgba(31,36,33,.08)` | hairline 分隔（透明墨，不用实色灰） |
| `--c-line-strong` | `rgba(31,36,33,.16)` | 输入框描边、hover 描边 |
| `--c-bg` | `#faf9f7` | 暖白墙面 · 页面底色 |
| `--c-bg-deep` | `#f1efeb` | 井底（输入静息、备注块、占位块） |
| `--c-surface` | `#ffffff` | 纯白表面 |
| `--c-primary` | `#356d5b` | 苔绿 · 主强调色（品牌线，与图标同源） |
| `--c-primary-deep` | `#2a5648` | 主色按压/hover |
| `--c-primary-soft` | `#edf3ee` | 标签浅底 |
| `--c-clay` | `#cf7f63` | 陶橘 · 焦点环、标题句点（小面积强调） |
| `--c-honey` | `#f4dc85` | 蜂蜜黄 · 胶带、想法便签、摘录条 |
| `--c-honey-mist` | `#fdf8e5` | 蜜雾 · 便签底渐变起点 |
| `--c-honey-ink` | `#57491f` | 胶带文字（蜂蜜上 ≈6.5:1） |
| `--c-wood` | `#cda572` | 木色 · 小熊 |
| `--c-danger/warning/success/info` | 见 tokens.css | 语义状态 |

**规则**
- 苔绿是交互色：主按钮、选中态、链接。陶橘是强调色：焦点环、标题句点，不铺面。
- **内容卡片区一律中性**：列表卡、想法卡、占位块、摘要块只用白/井底/hairline，
  暖色不进卡片。
- 蜂蜜黄只出现在胶带 eyebrow（一屏一次，属页眉不属于卡片）。
- 分隔一律 hairline（透明墨），不用实色灰线；深度只有「井底 / hairline」两级，无阴影层级。
- 渐变只允许一处：胶带的白斜纹；按钮、底色、卡片不做渐变。

## 三、排印

| 角色 | 字体 | 用法 |
|---|---|---|
| Display | `--font-serif`（宋体系）400 | 页标题、品牌字标、详情页标题——画廊的「展签」；3.2 起用常规字重（粗宋笨） |
| Body | `--font-sans` 400/500 | 一切阅读文本 |
| Data | `--font-mono` | 金额、尺寸、日期、编号（保留的图纸记忆点） |

- **不引 webfont**（沿用跨端决策）：serif 用系统字栈
  `Songti SC / STSong / Noto Serif SC / SimSun`。iOS/macOS 出宋体，
  Android 无衬线宋时降级为黑体——接受渐进增强。
- 字号阶梯（`--fs-*`）：9 微字 / 10 微标注 / 11 标签 / 12 说明 / 14 正文 /
  16 强调 / 20 卡片题·品牌 / 26 手机页题 / 34 桌面页题。
- 一个界面最多两种字重：正文 400 + 强调 500；serif 自带 700，不与 sans 混用字重语言。
- 行高：display 1.2 · 标题 1.4 · 正文 1.7 · 脚注 1.9。大标题字距 +0.5px（中文印刷感微正）。

## 四、间距 · 圆角 · 阴影 · 动效

- **间距**：4px 标尺 `--sp-1..16`（4/8/12/16/20/24/28/32/36/40/48/64）。
- **圆角（3.0 收紧）**：`--r-xs 4` · `--r-sm 8`（输入/小控件）· `--r-md 10`（按钮/图块）·
  `--r-lg 14`（面板）· `--r-xl 18`（弹层）· `--r-pill 999`。画廊气质挺括，不用大圆。
- **阴影（3.0 退役）**：常规界面**零阴影**，深度 = hairline + 井底两级；唯一保留
  `--shadow-sheet` 给弹层浮卡。图片边缘用 1px 内 outline（`rgba(31,36,33,.06)`），不是边框。
- **动效**：只做交互反馈，`--dur-fast 140ms` / `--dur-base 240ms`；弹层升起保留但放缓为
  ease-out。`prefers-reduced-motion` 全关。
- **层级**：`--z-nav 10` / `--z-modal 30` / `--z-toast 40`。

## 五、布局与断点（沿用）

外壳：PC/Pad 左侧栏（白墙 + hairline），手机底部导航（白条 + hairline）。内容单列优先。

```
桌面 >1100 侧栏244 · Pad 701–1100 侧栏190/150 · 手机 ≤700 底导
内容区最大宽 1220，页边距桌面 40 / 手机 21；触控目标 ≥ 44px。
```

- 断点：**≤700 手机**（底导）· **701–900 窄侧栏 150** · **901–1100 侧栏 190** · **>1100 标准 244**。
- 导航选中态只换颜色不改字重；焦点可见：`outline 2.5px --c-clay`。

## 六、消费规范（Do / Don't）

- ✅ 组件只写 `var(--c-primary)`、`var(--sp-4)`，不写 `#356d5b`、`16px`
- ✅ 新色先进 tokens.css 起名再使用；金额/尺寸/日期用 `--font-mono`
- ✅ 分隔用 `--c-line`（透明墨 hairline）；图片描边用 outline 不用 border
- ✅ 胶带/便签/摘录条按第一、二章签名位使用；小熊只出现在品牌位与空态
- ❌ 不用纯黑纯灰；不引第二套字体；不做毛玻璃；按钮与页面底色不做渐变
- ❌ 蜂蜜黄不进按钮/导航/正文色；陶橘不铺面；一屏最多一条胶带
- ❌ 导航选中态不改字重；卡片不叠阴影

## 七、图标

## 八、沿革

- **1.0「木作暖光的施工手册」**（2026-10-10）：苔绿/蜂蜜/小熊/胶带，暖工装隐喻。
- **2.0「纸感暖光」**（2026-10-10）：暖纸渐变、毛玻璃浮层、药丸按钮、双层阴影、
  弹性动效、胶带 eyebrow、小熊空态。毛玻璃/双层阴影/按钮渐变被 3.x 取代。
- **3.0「样板画廊」**（2026-10-11 上午）：画廊骨架确立（图块卡/文字页签/hairline/
  serif Display/平面按钮）；小熊胶带蜂蜜陶橘一度全部退场。
- **3.1「样板画廊 · 暖色签名」**（2026-10-11，当前）：应反馈品牌暖色回归——
  画廊骨架不动，小熊/胶带/蜂蜜黄/陶橘按「签名位」请回。

## 九、3.1 增补：暖色签名回归（2026-10-11）

在 3.0 骨架（图块卡、文字页签、hairline、serif、平面按钮、零阴影）完全保留的前提下，
品牌暖色元素回归，但**只驻留在壳层签名位，内容卡片区保持中性**：

1. **胶带 eyebrow 回归**：页眉引导语仍是斜贴蜂蜜胶带（白斜纹 + -1.5° 旋转），
   一屏最多一条。它是页眉署名，不是卡片样式。
2. **小熊回归**：侧栏品牌位、手机顶栏品牌、全部空态/错误态（坐在暖光圈里）。
   品牌区为横向（小熊 + serif 字标）。
3. **陶橘归位**：焦点环 `2.5px --c-clay`、标题句点陶橘色。
4. **内容卡片区一律中性**（当日晚些时候收紧）：想法卡 = 白底 hairline 文字块；
   无图占位块 = 井底色；详情摘要 = 井底引文块。蜂蜜黄不进任何卡片。
5. **不回潮**：按钮仍平面苔绿；导航仍纯色选中；浮层仍无毛玻璃；界面仍零阴影。

## 十、3.0 改版记录（2026-10-11）

1. **底色**：全 app 单一暖白 `--c-bg`，无渐变无光晕；侧栏/顶栏/底导 = 白 + hairline。
2. **卡片 → 画廊图块**：方案卡改竖排——图片 4:3 通栏置顶（移动端双列/桌面三列），
   无框无阴影，标题与 mono 元信息挂在图下；无图的想法卡见第九章 3.1 便签样式。
3. **分页签 → 文字页签**：选中 = 苔绿文字 + 2px 苔绿下划线；计数 mono 弱化。
4. **按钮 → 平面**：主按钮纯苔绿方块（r-md）；按压 scale(0.98)。
5. **serif Display**：页标题、品牌字标、详情标题宋体 700。
6. **弹层**：背板纯色墨（无 blur），浮卡 r-xl + 唯一保留的 `--shadow-sheet`；
   手机整层升起（ease-out 320ms）+ 抓手。
7. **输入**：井底 `--c-bg-deep` + hairline，聚焦描边变苔绿。

## 十一、3.2 瀑布流改造（2026-10-11，当前）

方案库列表按小红书样式重排（用户参考截图反馈）；同日参考小红书搜索结果页
（search_result_ai 页骨架 + 已知形态）二次校准：

1. **瀑布流**：CSS 多列——手机 2 列 / ≥700 两列宽距 / ≥1100 四列，卡片按内容自然
   高度垂落，`break-inside: avoid` 防截断。3.1 的「同行等高」规则随瀑布流废止
   （不等高正是瀑布流的节奏）。
2. **封面自然比例**（二次校准：废弃统一 3:4 裁切）：`mode="widthFix"` 按原图比例
   显示，瀑布流靠图高差异错落——小红书搜索页卡片即原始比例；CSS 给 `min-height`
   + 井底色兜底加载期；无图占位块固定 3:4。圆角 + 1px outline 不变；图下标题
   14px medium 2 行截断（小红书图题位）。
3. **分页签 → 胶囊页签**（二次校准：替换 3.0 文字下划线页签）：选中 = 浅苔底胶囊
   （`--c-primary-soft` + 深苔字），未选中纯文字，圆角 pill、36px 高——小红书
   搜索页「全部/图文/视频」胶囊 tab 的对应物；计数 mono 弱化不变。
4. **来源行**：`域名 · 日期` 左 + `打开 ↗` 右，11px 常规字重（不再用 mono 弱标注）。
5. **纯想法 = 蜜色语录卡**：蜜雾底块（min-height 220px，文字贴顶）+ serif 大引号 +
   想法正文 + 右下蜜色短划线——小红书文字卡的对应物。「卡片不进暖色」规则在此张卡
   上让位于样式参考；其余卡片仍中性。
6. **「添加想法」→ 右下角圆形悬浮钮**：56px flat 苔绿圆 + 白色加号（零阴影规则不破），
   fixed 右下；手机端抬高避开底导（76px + safe-area）。弹层打开时被 modal 层覆盖。
   页头不再放操作按钮。
7. **卡片点击 / 详情 = 小红书笔记详情式**（同日晚）：
   - 列表卡 hover：封面图内层 `scale(1.03)` 微放大（XHS 标志性 hover），标题变色保留。
   - 详情改为全屏覆盖层（z-modal）：桌面 = 半透明墨背景 + 居中大圆角 sheet
     （`--shadow-sheet`，左图右文两栏，图区墨底 contain 不裁切；点背景 / 右上白圆 X /
     ESC 关闭）；手机 = 全屏页（上图自然高度下文，关闭钮半透明白圆悬浮左上）。
     覆盖层场景例外于「纯色墨背板」规则（XHS 弹层式透出列表）。
   - 右栏顺序对齐 XHS：serif 标题（可编辑）→ 正文摘要（平铺，不再垫井底块）→
     标签胶囊（可增删）→ hairline 分割线 → 来源行（来源 · 日期 · 状态 +
     「打开原文 ↗」苔绿小钮，占 XHS 关注键位）→ 讨论与备注（评论区对应物，
     去面板框，流式排版 + 底部输入条）。
   - Taro 坑：H5 Image aspectFit 内层 img 绝对定位，容器 height:auto 塌 0——
     窄屏用 `widthFix`（按 `window.innerWidth > 700` 切换 mode）。
8. 占位块仍中性井底 + 弱图标；整体仍无边框、无阴影、零渐变（语录卡蜜雾底除外）。
