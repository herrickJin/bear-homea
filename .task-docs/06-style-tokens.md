# 06 · 整体风格与设计 Token

**状态**：✅ 完成（2026-10-10）

## 目标

在功能剥离（05）之后、正式功能重建之前，先定视觉地基：风格方向、色板、排印、
间距/圆角/阴影/动效 token，以及全站唯一签名元素，供后续每一页复用。

## 方向（详见 bear-home/DESIGN.md）

- **定位**：「木作暖光的施工手册」——工具感 + 家的温度；保留既有品牌资产（小熊、苔绿、slogan）
- **色彩**：材料出处命名的 13 色板（深林墨/暖墙白/苔绿/陶橘/蜂蜜/木色…），禁纯黑纯灰
- **排印**：系统中文字栈不引 webfont；三角色 = 标题/正文/**等宽数据**（金额尺寸日期用 mono，图纸标注感）
- **签名**：胶带标签（斜贴蜂蜜色胶带条，`rotate(-1.5deg)`），落在页眉 eyebrow，全站唯一放胆处
- **自查**：避开「奶油底+衬线+赤陶」等三类 AI 默认样式；每个选择能追到装修材料世界

## 交付

| 文件 | 内容 |
|------|------|
| `bear-home/src/styles/tokens.css` | **唯一真源**：色彩/排印/间距/圆角/阴影/动效/层级/布局共 8 组 token，挂在 `page` + `.app-shell`（小程序无 `:root`） |
| `bear-home/src/styles.css` | 全量改为消费 token；eyebrow 落地签名胶带；移除内联变量定义 |
| `bear-home/DESIGN.md` | 风格方向 + token 手册 + Do/Don't 规范 |

## 与旧样式的关系

- 色值全部沿用既有品牌色（不换色），只是**收编命名 + 语义化**；个别手工灰轻微收敛到
  `--c-faint/--c-mute`（如侧栏标签 #a1aaa5 → --c-faint），肉眼不可辨
- 间距吸附 4px 标尺，个别 ±2px（导航 gap 10→12、topbar gap 18→16、面板 padding 23→24）
- 删除旧的 `--green/--mint/--coral` 变量，统一为 `--c-*` 命名（旧变量无外部引用）
