# 熊熊之家 · 视觉方向与设计 Token

> 单一真源。Token 定义在 `src/styles/tokens.css`，本文件解释「为什么」并规定「怎么用」。
> 改任何颜色 / 字号 / 间距：先改 tokens.css，再全局消费，页面里不出现裸十六进制。
> **当前生效方向：3.0「样板画廊」**（见第八、九章）；第二~七章为 3.0 现行规范。

## 一、风格定位

**「样板画廊」——家还没装完，App 是未来之家的画廊。**（3.0，2026-10-11 定）

用户是第一次装修的小两口，装修要熬 6~10 个月，每天在小红书收集的是**图片**。
App 的第一职责是把它们大幅、安静、体面地挂出来；工具感藏在排版和 mono 数据里，
不再靠拟物隐喻（胶带/工地）表达。

- **基调**：暖白墙面做底，图片是绝对主角，界面退后。安静、克制、留白。
- **装饰**：零装饰。深度只靠 hairline 分隔；苔绿是唯一强调色。
- **出处**：画廊白墙 / 美术馆图签 / 印刷刊物。拒绝拟物纹理与材质隐喻。

## 二、色彩

| Token | 色值 | 角色 |
|---|---|---|
| `--c-ink` | `#1f2421` | 标题与正文（带一丝绿意的近黑） |
| `--c-ink-2` | `#434a45` | 次级标题 |
| `--c-mute` | `#6d736e` | 辅助文字（白底 ≈4.9:1） |
| `--c-faint` | `#a3a8a2` | 弱标注、页脚 |
| `--c-line` | `rgba(31,36,33,.08)` | hairline 分隔（透明墨，不用实色灰） |
| `--c-line-strong` | `rgba(31,36,33,.16)` | 输入框描边、hover 描边 |
| `--c-bg` | `#faf9f7` | 暖白墙面 · 页面底色 |
| `--c-bg-deep` | `#f1efeb` | 井底（输入静息、备注块、占位块） |
| `--c-surface` | `#ffffff` | 纯白表面 |
| `--c-primary` | `#356d5b` | 苔绿 · 唯一强调色（品牌线，与图标同源） |
| `--c-primary-deep` | `#2a5648` | 主色按压/hover |
| `--c-primary-soft` | `#edf3ee` | 标签浅底 |
| `--c-danger/warning/success/info` | 见 tokens.css | 语义状态 |

**规则**
- 苔绿只出现在：主按钮、选中态文字、链接、焦点环。**不铺面、不做底色块。**
- 分隔一律 hairline（透明墨），不用实色灰线；深度只有「井底 / hairline」两级，无阴影层级。
- 3.0 退休：蜂蜜黄、陶橘、木色、蜜雾、一切渐变。小熊与胶带从所有界面退场
  （组件保留在代码库，不再引用）。

## 三、排印

| 角色 | 字体 | 用法 |
|---|---|---|
| Display | `--font-serif`（宋体系）700 | 页标题、品牌字标、详情页标题——画廊的「展签」 |
| Body | `--font-sans` 400/500 | 一切阅读文本 |
| Data | `--font-mono` | 金额、尺寸、日期、编号（保留的图纸记忆点） |

- **不引 webfont**（沿用跨端决策）：serif 用系统字栈
  `Songti SC / STSong / Noto Serif SC / SimSun`。iOS/macOS 出宋体，
  Android 无衬线宋时降级为黑体——接受渐进增强。
- 字号阶梯（`--fs-*`）：9 微字 / 10 微标注 / 11 标签 / 12 说明 / 14 正文 /
  16 强调 / 20 卡片题·品牌 / 26 手机页题 / 34 桌面页题。
- 一个界面最多两种字重：正文 400 + 强调 500；serif 自带 700，不与 sans 混用字重语言。
- 行高：display 1.2 · 标题 1.4 · 正文 1.7 · 脚注 1.9。大标题字距 +0.5px（中文印刷感微正）。

## 四、间距 · 圆角 · 阴影 · 动效

- **间距**：4px 标尺 `--sp-1..16`（4/8/12/16/20/24/28/32/36/40/48/64）。
- **圆角（3.0 收紧）**：`--r-xs 4` · `--r-sm 8`（输入/小控件）· `--r-md 10`（按钮/图块）·
  `--r-lg 14`（面板）· `--r-xl 18`（弹层）· `--r-pill 999`。画廊气质挺括，不用大圆。
- **阴影（3.0 退役）**：常规界面**零阴影**，深度 = hairline + 井底两级；唯一保留
  `--shadow-sheet` 给弹层浮卡。图片边缘用 1px 内 outline（`rgba(31,36,33,.06)`），不是边框。
- **动效**：只做交互反馈，`--dur-fast 140ms` / `--dur-base 240ms`；弹层升起保留但放缓为
  ease-out。`prefers-reduced-motion` 全关。
- **层级**：`--z-nav 10` / `--z-modal 30` / `--z-toast 40`。

## 五、布局与断点（沿用）

外壳：PC/Pad 左侧栏（白墙 + hairline），手机底部导航（白条 + hairline）。内容单列优先。

```
桌面 >1100 侧栏244 · Pad 701–1100 侧栏190/150 · 手机 ≤700 底导
内容区最大宽 1220，页边距桌面 40 / 手机 21；触控目标 ≥ 44px。
```

- 断点：**≤700 手机**（底导）· **701–900 窄侧栏 150** · **901–1100 侧栏 190** · **>1100 标准 244**。
- 导航选中态只换颜色不改字重；焦点可见：`outline 2px --c-primary`。

## 六、消费规范（Do / Don't）

- ✅ 组件只写 `var(--c-primary)`、`var(--sp-4)`，不写 `#356d5b`、`16px`
- ✅ 新色先进 tokens.css 起名再使用；金额/尺寸/日期用 `--font-mono`
- ✅ 分隔用 `--c-line`（透明墨 hairline）；图片描边用 outline 不用 border
- ❌ 不用纯黑纯灰；不引第二套字体；不做渐变、毛玻璃、彩色底块
- ❌ 导航选中态不改字重；卡片不叠阴影

## 七、图标

PNG 三色（green `#356d5b` / muted / white）由 `scripts/generate-icons.cjs` 生成，
`npm run icons` 重跑。苔绿未变，3.0 无需重生成；若改 `--c-primary` 必须同步脚本。

## 八、沿革

- **1.0「木作暖光的施工手册」**（2026-10-10）：苔绿/蜂蜜/小熊/胶带，暖工装隐喻。
- **2.0「纸感暖光」**（2026-10-10）：暖纸渐变、毛玻璃浮层、药丸按钮、双层阴影、
  弹性动效、胶带 eyebrow、小熊空态。其「渐变/胶带/毛玻璃/蜂蜜」规则已被 3.0 取代。

## 九、3.0「样板画廊」改版记录（2026-10-11）

1. **底色**：全 app 单一暖白 `--c-bg`，无渐变无光晕；侧栏/顶栏/底导 = 白 + hairline。
2. **卡片 → 画廊图块**：方案卡改竖排——图片 4:3 通栏置顶（移动端双列/桌面三列），
   无框无阴影，标题与 mono 元信息挂在图下；无图的想法卡 = 白底 hairline 文字块。
3. **分页签 → 文字页签**：去药丸底，选中 = 苔绿文字 + 2px 苔绿下划线；计数 mono 弱化。
4. **按钮 → 平面**：主按钮纯苔绿方块（r-md），去渐变/投影/字距戏法；按压 scale(0.98)。
5. **serif Display**：页标题、品牌字标、详情标题改宋体 700；标题句点改苔绿。
6. **弹层**：背板纯色墨（无 blur），浮卡 r-xl + 唯一保留的 `--shadow-sheet`；
   手机仍整层升起（ease-out 320ms）+ 抓手。
7. **空态**：纯文字居中 + 主按钮，无小熊无光晕。
8. **输入**：井底 `--c-bg-deep` + hairline，聚焦仅描边变苔绿（去光环）。
