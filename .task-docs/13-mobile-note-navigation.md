# 手机笔记详情返回（2026-10-18）

- 手机/平板（窗口宽度 ≤1099）从列表打开笔记时，使用已注册的 inspiration-detail 路由；桌面保留原地覆盖层。
- 移动网页详情支持向左或向右横滑返回，内容跟随手指移动，释放后以阻尼弹簧完成返回或回弹；减少动态效果设置下保留透明度反馈。
- 10px 后判断方向；纵向优先时交还浏览器滚动，保留双指缩放。距离/速度判定返回，短滑和 pointercancel 回弹。
- 表单、按钮、链接、文本选择不抢手势；正在编辑或存在未发送备注时停用横滑返回。
- 返回走 Taro 页面栈，浏览器返回同样回列表；直接打开/刷新详情只有一层页面时，关闭跳转至列表。
- 列表 useDidShow 刷新数据，保留原有搜索和筛选状态。
- 实现：hooks/useSwipeBack.ts、LinkDetailSheet、inspiration/index 与 inspiration-detail/index。

验证：类型检查、H5 构建、小程序构建通过。Chromium 模拟触屏验证双向滑动返回、短滑回弹、纵向滚动、未发送备注保护、浏览器返回、搜索保留、详情直链返回与桌面覆盖层。iOS Safari/Android 真机手势手感待用户体验。
