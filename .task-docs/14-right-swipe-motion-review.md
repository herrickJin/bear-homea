# 笔记详情右滑动效审查与修正（2026-10-18）

应用 review-animations 技能与 STANDARDS.md，仅审查并修正手机详情的返回动效。

| Before | After | Why |
| --- | --- | --- |
| 左右横滑均返回 | 仅右滑返回，左滑不移动页面 | 返回方向明确；图片轮播继续独立处理左右滑动 |
| Taro 300ms 路由动画 + 详情层 240ms 动画 | 关闭内置 H5 路由动画；手机详情由单个页面层控制 | 消除方向/时序叠加，松手后不再追加路由动画 |
| JS 弹簧逐帧等待位置、速度都趋零 | 合成器 WAAPI：200ms 完成退场，160ms 回弹 | 去掉长尾等待；drawer 曲线取自技能标准 |
| 只移动 sheet，后方是详情页空壳 | 移动整个详情页面，拖动时临时显示原列表 | 与“返回上一页面”空间关系一致；避免滑走后再跳一屏 |
| 每帧更新父级 CSS 变量驱动背景 | rAF 合并拖动更新，直接设置页面 transform；释放后用 WAAPI | 降低继承变量引起的样式重算；只动 transform/opacity |
| 动效中抓取可能跳到逻辑位置 | 取消 WAAPI 前读取当前 presentation transform | 在中途重新抓取时保持连续位置 |

代码：src/hooks/useSwipeBack.ts、useSheetMotion.ts、LinkDetailSheet.tsx、inspiration.css、app.config.ts。

验证：类型检查、H5/小程序构建；模拟事件验证右滑完成返回、左滑不触发、160ms 回弹、回弹中重新抓取位置误差 0px、未发送备注保护、关闭按钮返回、图片轮播不触发返回、减少动态效果只使用 100ms opacity 且不移动页面。曾用原生触控注入验证右拖120px时页面位移120px、露出真实列表；后续浏览器触控注入未投递事件，补充测试使用合成 PointerEvent。浏览器截图工具未能输出截图，不声称已完成真机帧率或视觉流畅度验证。

结论：原实现 Block（叠加动效、长尾与空间关系错误）；本次修正通过代码及模拟行为审查。iOS/Android 真机手感待体验。
