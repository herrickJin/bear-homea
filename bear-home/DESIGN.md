# 熊熊之家 · 视觉方向与设计 Token

> 单一真源。Token 定义在 `src/styles/tokens.css`，本文件解释「为什么」并规定「怎么用」。
> 改任何颜色 / 字号 / 间距：先改 tokens.css，再全局消费，页面里不出现裸十六进制。

## 一、风格定位

**「木作暖光的施工手册」**——用户是第一次装修的小两口，房子是 89m² 的两室一厅，
装修要熬 6~10 个月。App 的气质应当是：**像一个懂行又温柔的朋友陪在现场**——
工具感（清楚、可靠、有标注）+ 家的温度（暖、慢、有小熊）。

- **基调**：冷调暖白的墙面感底色 + 森林系绿 + 暖饰点缀。安静、耐看、不焦虑。
- **克制**：全局扁平轻阴影，装饰只在两处出现——胶带标签与小熊。
- **出处**：每个颜色都能说出材料名（墙漆、苔藓、陶罐、蜂蜜、木头），拒绝凭空的「品牌色」。

## 二、色彩

| Token | 色值 | 材料名 | 职责 |
|---|---|---|---|
| `--c-ink` | `#293f39` | 深林墨 | 标题与正文 |
| `--c-ink-2` | `#536c5b` | 墨苔 | 次级标题（空态标题等） |
| `--c-mute` | `#68766e` | 岩灰 | 辅助文字、面包屑（白底 ≈4.8:1） |
| `--c-faint` | `#a9b4ac` | 浅岩 | 弱标注、页脚 |
| `--c-line` | `#e9eeea` | 素线 | 分割线、描边 |
| `--c-bg` | `#f7f9f6` | 暖墙白 | 页面底色（乳胶漆微暖白） |
| `--c-surface` | `#ffffff` | 白墙 | 卡片 / 面板表面 |
| `--c-primary` | `#356d5b` | 苔绿 | 主色：选中态、主按钮、品牌 |
| `--c-primary-deep` | `#2a5648` | 深苔 | 主色按压态 |
| `--c-primary-soft` | `#e8f2e9` | 浅苔 | 主色浅底：选中导航、标签底 |
| `--c-clay` | `#d59076` | 陶橘 | 焦点环、标题句点等强调点 |
| `--c-honey` | `#f4dc85` | 蜂蜜黄 | 胶带标签、点亮式点缀 |
| `--c-wood` | `#cda572` | 木色 | 小熊与暖饰 |
| `--c-on-primary` | `#ffffff` | — | 主色上的文字 |
| `--c-success/warning/danger/info` | 见 tokens.css | — | 语义状态（初版值，随功能落地校准） |

**规则**
- 页面从不直接用黑（`#000`）与纯灰，一律走 `--c-ink` 系，绿色调保持统一的「墨」感。
- 苔绿只做「可交互 / 当前」语义；陶橘只做强调与焦点，不铺面；蜂蜜黄只出现在胶带与小面积点缀。
- 对比度底线：正文 ≥ 4.5:1，大字 ≥ 3:1（胶带文字 `#57491f` on 蜂蜜 ≈ 6.5:1）。

## 三、排印

**角色分工（三角色）**

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题 Display | `--font-sans` 650 重量 + `--ls-title` 字距 | 页标题 `小家.`，大而稳 |
| 正文 Body | `--font-sans` 400/600 | 一切阅读文本 |
| 数据 Data | `--font-mono`（ui-monospace） | **金额、尺寸、日期、编号**——呼应图纸/清单的标注感，是排印上的品牌记忆点 |

**不引 webfont**：小程序 + H5 双端一致性、包体与真机加载考虑，用系统中文字栈
（PingFang SC / Microsoft YaHei）。个性来自重量、字距与等宽数字的组合，而非字体文件。

**字号阶梯**（`--fs-*`，px）：

```
9 微字   10 微标注  11 标签   12 说明   14 正文(默认)
16 强调  20 卡片题/品牌  26 手机页题  34 桌面页题
```

- 字重：400 常规 / 500 中 / 600 次级标题·强调 / 650 大标题。
- 行高：`--lh-display 1.2`（页标题，大字收紧行高）、`--lh-tight 1.4`（标题）、`--lh-base 1.7`（正文）、`--lh-loose 1.9`（脚注类）。
- 字距：`--ls-label 2px`（eyebrow、区块名，全大写感的标签拉开）、`--ls-title 0.5px`（大标题，中文印刷感微正）。
- 13 / 15 / 17 / 21px 属组件级特例（头像字、图标号），不进阶梯。

## 四、间距 · 圆角 · 阴影 · 动效

- **间距**：4px 基准标尺 `--sp-1..16`（4/8/12/16/20/24/28/32/36/40/48/64）。
  新代码靠拢标尺；存量个别值（37px 页边距等）允许保持，改版时归拢。
- **圆角**：`--r-sm 8`（小控件）· `--r-md 12`（按钮）· `--r-lg 16`（卡片/面板）· `--r-xl 22`（手机大面板）· `--r-pill 999`。
  卡片一律圆角，**不用 0 圆角的报纸风**——家的气质是圆润的。
- **阴影**：墨绿调、轻量三级（`--shadow-sm/md/lg`）。面板默认无阴影靠描边 `--c-line`，浮层才用阴影。
- **动效**：`--dur-fast 150ms` 按压 · `--dur-base 250ms` 展开 · `--dur-slow 400ms` 页面级；
  `--ease-out` 出场、`--ease-spring` 弹性点缀。**只在交互反馈处动**，无自动播放动画；
  `prefers-reduced-motion` 全关（已有规则）。
- **层级**：`--z-nav 10` / `--z-modal 30` / `--z-toast 40`。

## 五、签名元素（唯一的冒险）

**胶带标签 · tape label**——页眉 eyebrow 做成一条斜贴的蜂蜜色胶带：

```css
.eyebrow {
  background: repeating-linear-gradient(45deg, …白斜纹…), var(--c-honey);
  color: #57491f;
  transform: rotate(-1.5deg);   /* 手贴的歪 */
  border-radius: 2px;           /* 胶带是方角，不是圆角 */
}
```

出处：工地美纹胶带、材料样板上的标签贴。全站**只此一处**放胆，
其余控件保持安静；后续阶段标签（水电/泥木…）可复用同一 primitive，
但同一屏最多出现一次胶带。小熊是第二个品牌符号，但它是「角色」不是「样式」，不扩散到装饰。

## 六、布局与断点

外壳：PC/Pad 左侧栏（装订线/目录），手机底部导航（拇指区）。内容单列优先，卡片网格次之。

```
桌面 >1100           Pad 701–1100            手机 ≤700
┌────┬──────────┐   ┌──┬───────────┐   ┌──────────────┐
│侧栏│ 顶栏     │   │窄│ 顶栏      │   │ 顶栏(品牌)   │
│244 │ ┌──────┐ │   │栏│ ┌───────┐ │   │ ┌──────────┐ │
│    │ │内容区│ │   │150│ │内容区 │ │   │ │ 内容区    │ │
│    │ └──────┘ │   │  │ └───────┘ │   │ └──────────┘ │
└────┴──────────┘   └──┴───────────┘   │══底部导航════│
                                       └──────────────┘
```

- 断点：**≤700 手机**（底导）· **701–900 窄侧栏 150** · **901–1100 侧栏 190** · **>1100 标准 244**。
- 内容区最大宽 `--layout-content-max 1220`，页边距桌面 44 / 手机 21。
- 触控目标 ≥ 44px（底导 min-height 44 已满足）；焦点可见：`outline 3px --c-clay`。

## 七、消费规范（Do / Don't）

- ✅ 组件只写 `var(--c-primary)`、`var(--sp-4)`，不写 `#356d5b`、`16px`
- ✅ 新色先进 tokens.css 起「材料名」，再使用
- ✅ 金额/尺寸/日期用 `--font-mono`
- ✅ 动效只做交互反馈，时长从 `--dur-*` 选
- ❌ 不用纯黑纯灰；不引入第二套字体；不复制粘贴十六进制
- ❌ 不做整屏渐变、不铺大面积陶橘/蜂蜜

## 八、2.0「纸感暖光」全面改版记录（2026-10）

1.0 是「平整的施工手册」；2.0 在不换风格基因（苔绿/蜂蜜/小熊）的前提下，
让每一层都有物理感：纸落在桌上、玻璃浮在纸上、光打在墙上。

- **底色**：页面由平色改为暖纸渐变（右上蜂蜜光晕 + 左侧苔绿晕染）；侧栏改亚麻底（`--c-bg-deep`），
  内容区因此成为「亮处」。
- **浮动层材质**：顶栏（桌面+手机）、底部导航、手机吸顶工具条统一毛玻璃
  （`--material-*`），顶栏改 `position: sticky`，内容从玻璃下滚过。
- **按钮**：小主按钮改药丸形（微渐变 + 苔绿染色投影 + 按压缩放 0.96）；
  弹层 CTA 46px 高、字距 4px；全部按钮统一 pointer-down 即缩的按压反馈。
- **卡片**：圆角 18 + 双层阴影（接触影+悬浮影）；hover 上浮 2px；按压即沉回。
  想法卡 = 蜜雾便签底 + 左蜜条；链接卡 = 白纸。
- **标签**：`⌗` 前缀退役，改为浅苔药丸 + 前置圆点（`chip-dot`，结构化元素，跨端可靠）。
- **输入**：静息沉入 `--c-bg-deep`，聚焦浮起白底 + 苔绿光环（`focus-within`）。
- **弹层**：背板改深墨玻璃（blur 6px）；手机端整层从底部升起（`--ease-sheet` 快起缓落，
  460ms）+ 顶部小抓手；进出同路径。
- **导航**：侧栏选中项 = 亚麻底上的白色浮起药丸；底部导航选中 = 图标后浅苔药丸垫。
- **空态**：小熊坐进一圈暖光（双层 box-shadow 光晕）。
- **详情页**：AI 摘要改「蜂蜜摘录条」（蜜雾底 + 左蜜条）；标题升为 display 字重。
- **图标色不变**（`#356d5b` 系），与既有 PNG 图标保持同源；改色需同步
  `scripts/generate-icons.cjs` 并重跑 `npm run icons`。
